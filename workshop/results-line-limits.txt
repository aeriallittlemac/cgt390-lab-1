Line-item limit test for POST /api/orders
Script: node scripts/test-line-limits.mjs (http://localhost:3000, local dev server)
Date: 2026-11-01. validateOrder() and the schema were not changed.

Findings
- There's no limit on how many lines an order can have. Every cart size up to
  1,000 lines returned 201.
- Every accepted order stored exactly as many order_items rows as it submitted.
  The row counts come from the SQLite file, not from the API.
- Response size grows with the line count, about 143 bytes per line. A 1,000-line
  order returns about 143 KB.
- Total request time stayed between 12 and 47 ms at every size, across both runs.
  Random variation was larger than any effect of cart size, so these runs show no
  slowdown. The time is measured in the script, from sending the request to
  receiving the last byte; it is not database time.
- Every cart repeats one line: pizza-margherita, 14", Thin, toppings ["Garlic"], qty 1.
  Each size was tried 3 times.
